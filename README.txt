SEND TO PC - Android share target -> your PC file-share server

1. Create a GitHub repo (e.g. drdevrd/SendToPC), upload ALL these files/folders (keep .github folder).
2. Push to main. GitHub Actions builds the APK -> Releases > "latest" > SendToPC.apk
3. Install APK, open app once (allow notifications), tap TEST CONNECTION.
4. In any app: Share > Send to PC.

Defaults: https://files.hshospitalcbe.in  user asd / pass asd (change in app).
Shared text/links are saved as text-DATE.txt in shared_files.
